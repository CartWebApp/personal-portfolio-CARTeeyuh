EECU BUDGET CALCULATOR

Intended Audience:

Newly Graduated Students

Young Adults

Those who don't know how to budget

What's its purpose?

This budget calculator is intended for young adults to leanr how to efficiently budget every month, but also to just do all the calculations for you. This simpifies the overall process, leading to less stress.

Technology stack

Languages: HTML5, CSS3, and Vanilla Javascript

Tools: Visual Studio Code (Development), Github

Deployement: Hosted via Netlify for global accessibility>
