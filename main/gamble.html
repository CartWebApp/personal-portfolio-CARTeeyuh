The Goddess's Gamble

Description

A game played purely inside the webpage that consisted of many interactions, endings, and routes the player could pick. The purpose of this game was to intensify my knowledge of Javascript while having a little fun doing it.

The Technology Stack

    Languages: HTML, CSS3, and Vanilla JavaScript

    Tools: Visual Studio Code for developmenet and Git/GitHub for version control

    Deployment: Hosted via Netlify to ensure global accessibility and performance.

Challenges & Solutions

    Challenge 1

    Me and my partner had a lack of communication and middle ground between one another.

    Solution 1

    Had to realize we thought differently and we must put our own wants aside to create something we would both agree on.

    Challenge 2

    Javascript was difficult to grasp fully due to all of the different systems we were planning to add.

    Solution 2

    Made many of the functions have semantic names that were easy to understand, which in turn made coding a lot easier.

    Challenge 3

    Struggled to make a solid visual representation on what the game should look like.

    Solution 3

    Decided to make the game look like the generic setting of a generic “hero”, which my partner I believe is the medieval time/middle ages (roughly 476AD - 1000AD).

Investigate

Me and my partner investigated what the middle ages was like and added our own fantasy twist to it.

Connect

Connected with my partner as we communicated thoroughly with each other to make our game as good as we could possibly make it.
